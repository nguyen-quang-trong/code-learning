## Xác định kết quả khi thực thi list 
Cho list 

```python
lst = [3, 0, 1, 5, 2]
x = 2
```

(a) lst[0] = 3

(b) lst[3] = 5

(c) lst[x] = lst[2] = 1

(d) lst[-x] = lst[-2] = 5

(e) lst[x+1] = lst[3] = 5

(f) lst[x] + 1 = lst[2] + 1 = 1 + 1 = 2

(g) lst[lst[x]] = lst[lst[2]] = lst[1] = 0

(h) lst[lst[lst[x]]] = lst[lst[1]] = lst[0] = 3

## Xác định kết quả khi thực thi list 
Cho list

```lst = [20, 1, -34, 40, -8, 60, 1, 3]```

(a) lst = [20, 1, -34, 40, -8, 60, 1, 3]

(b) lst[0:3] = [20, 1, -34]

(c) lst[4:8] = [-8, 60, 1, 3]

(d) lst[4:33] = [-8, 60, 1, 3]

(e) lst[-5:-3] = [40, -8]

(f) lst[-22:3] = [20, 1, -34]

(g) lst[4:] = [-8, 60, 1, 3]

(h) lst[:] = [20, 1, -34, 40, -8, 60, 1, 3]

(i) lst[:4] = [20, 1, -34, 40]

(j) lst[1:5] = [1, -34, 40, -8]

(k) -34 in lst = True

(l) -34 not in lst = False

(m) len(lst) = 8
